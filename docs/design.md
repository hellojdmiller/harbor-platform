# Harbor interface direction

A personal assistant home should feel like a clear desk: a greeting, one place to ask, work in progress, and suggestions. IT manages the same system from an explicit administration area. The supplied Town screenshots inform information hierarchy; Harbor uses its own identity and implementation.

Palette: paper #ffffff, mist #f5f7f6, ink #202b2c, muted #6b7778, harbor teal #23766c, pale teal #e7f2ee. Typography: locally served Geist Sans for readable controls and conversational headings; no decorative display font. One quiet sidebar, wide left-aligned task composer, narrow contextual rail. On mobile the rail becomes a lower section and navigation stays keyboard accessible.

```
Navigation | Greeting                               Agent profile
           | Composer                       | Suggestions
           | Recent work                    | Connections
```

Critique: a dashboard of equal metric cards would put IT concerns ahead of the user's task. The home instead gives the composer most of the space. Administration uses tables and operational status, while the wiki uses a page index and readable prose. Color marks useful actions and status, with no decorative gradients.

An explicit read-only demo contains invented names and records. The authenticated application uses Convex subscriptions; demo content is never seeded into a live workspace.
